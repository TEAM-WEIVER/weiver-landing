# 제품 화면 리소스 교체 가이드

랜딩의 `서비스 미리보기`는 아래 네 장의 실제 제품 화면으로 교체할 준비가 되어 있습니다. 현재는 시각적 자리표시자만 표시합니다.

| 순서 | 권장 파일명 | 화면 내용 | 권장 비율 |
| --- | --- | --- | --- |
| 01 | `01-profile-registration.webp` | 이력서·포트폴리오 등록 | 4:3 또는 16:10 |
| 02 | `02-ai-interview.webp` | AI 면접 진행 | 4:3 또는 16:10 |
| 03 | `03-capability-profile.webp` | 완성된 역량 프로필 | 4:3 또는 16:10 |
| 04 | `04-company-contact.webp` | 기업 컨택·제안 수신 | 4:3 또는 16:10 |

- WebP 또는 PNG를 사용하고, 각 파일은 1MB 이하를 권장합니다.
- 개인정보·실제 회사명·개인 식별 정보는 마스킹합니다.
- 전달 위치는 `assets/product/`로 하면 됩니다. 파일을 받으면 각 스켈레톤의 `data-resource` 위치에 실제 이미지를 연결합니다.
